# B Key – Two-Color 3D Printing Instructions

This STL is designed to be printed in two colors to make the lettering stand out against the keycap. You can accomplish this with a single-filament 3D printer by manually pausing the print and swapping filament.

## Printing Instructions

1. **Start the print** using your primary filament color. I use **black** to match the original keypad.
2. **Pause the printer at layer 22.** Set this pause in your slicer before starting the print.
3. **Change the filament** to a contrasting color. I use **white** to make the lettering stand out.
4. **Print one layer** using the contrasting filament.
5. **Pause the printer again** after that layer is complete.
6. **Switch back to your original filament color** (black in my case).
7. **Resume printing** and allow the print to finish.

## Example Color Configuration

| Print Section | Filament Color |
|---|---|
| Layers 1–21 | Black |
| Layer 22 | White |
| Layer 23 onward | Black |

*Note: Layer numbering may vary between slicers. Verify the layer preview and pause positions before printing.*

## Tips

- Choose two colors with strong contrast so the lettering is easy to read.
- Purge the previous filament color completely when switching to avoid color contamination.
- Make sure the printer maintains its position during filament changes.
- This method does not require an AMS or other automatic multicolor system.

The result is a clean, two-color keycap that matches the keypad while making the lettering easy to see.
